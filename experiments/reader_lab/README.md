# Mia Legilo Reader Lab

Experimental Android benchmark for choosing an EPUB engine. This is not the Mia Legilo application. It does not talk to Calibre-Web, create accounts, or sync a library.

## What is here

- `experiments/reader_lab` hosts epub_rtl 0.1.0, flutter_epub_viewer 2.2.1, and a vendored Foliate-js host.
- `engines/flutter_readium_app` is a separate app for flutter_readium 0.9.1. Readium needs `compileSdk` 37 and `FlutterFragmentActivity`, so it is not forced into the first app.
- `packages/benchmark_core` holds locators, bookmarks, and the scoring rule that refuses a weighted score until every hard requirement has a device pass.
- `assets/test_books` is original CC0 text generated by `scripts/generate_corpus.py`.
- `assets/foliate` is the EPUB subset of readest/foliate-js at commit `090ccca6989a904f6df343538902bd8431c5a7a5`, MIT, plus an original host page. No Readest application code is included.

## Run the lab

Flutter 3.47.9 and Dart 3.13.7 were used. Android debug APKs compiled against SDK 36 (Reader Lab) and SDK 37 (Readium lab). They were not installed on a device.

```bash
cd experiments/reader_lab
python3 scripts/generate_corpus.py
flutter pub get
flutter test
flutter analyze
flutter build apk --debug
flutter run -d <android-device-id>
```

The Readium app:

```bash
cd experiments/reader_lab/engines/flutter_readium_app
flutter pub get
flutter analyze
flutter build apk --debug
flutter run -d <android-device-id>
```

Regenerate the shared books, then copy them before rebuilding Readium:

```bash
python3 experiments/reader_lab/scripts/generate_corpus.py
cp experiments/reader_lab/assets/test_books/*.* \
  experiments/reader_lab/engines/flutter_readium_app/assets/test_books/
```

## What has been verified

`flutter test` in the Reader Lab passed, including:

- epub_rtl scroll mode puts many short chapters in one `CustomScrollView` and not a `PageView`.
- Scrolling reaches a later chapter and, after a programmatic jump, an earlier chapter, without a chapter button.
- `display: none` text from EPUB-004 is absent. EPUB-005's table cell and image widget are present.
- The same epub_rtl block is still visible after a larger font and line height.
- One tap on the reader bookmark control stores that anchor and a second tap removes it. No dialog is opened.
- Locator JSON, bookmark files, and the "no weighted score without device passes" rule.

These widget tests run in the Flutter test binding. They are not Android device results and they do not measure frame time, memory, or fling momentum.

`flutter build apk --debug` succeeded for both apps. Compilation does not show that scrolling, restoration, or bookmarking works on Android.

No emulator was started. No physical device was attached. E-ink behavior was not measured.
