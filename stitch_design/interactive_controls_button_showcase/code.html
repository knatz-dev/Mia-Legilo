State Matrix (Interactive Dynamics)

Tactile physical feedback

In a physical book or notebook, pressure indents the paper. In Mia Legilo, the Pressed State eliminates the offset drop-shadow and translates the button down-right by 2px to mimic a physical stamp. The Disabled State replaces crisp strokes with dashed charcoal-disabled lines.
