# Mia-Legilo

Mia-Legilo is a reading and personal library organization frontend for Calibre-Web NextGen (CWNG), not a general-purpose EPUB reader. Its books correspond to entries in the connected CWNG library; downloaded copies enable offline reading.

## Language

**Personal library organization**:
The reader's named shelves, book memberships and reading statuses, distinct from editing the server's catalog metadata or administering the server.
_Avoid_: Catalog administration, server management

**Server catalog metadata**:
The server-maintained descriptions of books, such as titles, authors, tags and series. This is distinct from a reader's progress or bookmarks.
_Avoid_: Reading state, personal organization
