# ADR-001: EPUB Renderer Selection

**Status:** Accepted (validation pending)
**Date:** 2026-11-14
**Decision:** Use Foliate-js (Readest fork) as the primary EPUB renderer.

## Context
Mia Legilo requires continuous cross-chapter vertical scrolling, semantic locators, offline reading, and Android WebView isolation. Two candidates: Foliate-js and epub_rtl.

## Decision
Foliate-js (Readest fork) is selected. Pinned commit: `22a49acaa120877ede21f713679ab8ba4d1ef663`.

## Rationale
- MIT licensed.
- Supports EPUB 2/3, continuous scrolling, CFI locators, TOC, search, bookmarks.
- WebView-based, integrates with Flutter via webview_flutter.
- Active maintenance (Readest).

## Consequences
- Requires WebView isolation, bridge protocol, license/SBOM audit.
- Performance and memory must be measured on device (G2).
- epub_rtl remains comparative evidence only.

## Hard gates (must pass before release)
- 30 cross-chapter transitions both directions without discontinuity.
- 100 semantic restoration trials with exact/approximate reporting.
- No unbounded memory growth across 30 transitions.
- TalkBack traversal and 48dp touch targets.
- Hostile-EPUB security tests.

## Reopen conditions
If a hard gate fails and cannot be remediated, reopen ADR-001.
