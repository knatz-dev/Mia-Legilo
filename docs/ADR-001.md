# ADR-001: EPUB Renderer Selection

**Status:** Accepted (validation in progress — emulator verified; physical device gates pending)
**Date:** 2026-11-14
**Decision:** Use Foliate-js (Readest fork) as the primary EPUB renderer.

## Context
Mia Legilo requires continuous cross-chapter vertical scrolling, semantic locators, offline reading, and Android WebView isolation. Two candidates: Foliate-js and epub_rtl.

## Decision
Foliate-js (Readest fork) is selected. Pinned commit: `22a49acaa120877ede21f713679ab8ba4d1ef663`.

## Rationale
- MIT licensed.
- Supports EPUB 2/3, continuous scrolling, CFI locators, TOC, search, bookmarks.
- WebView-based, integrates with Flutter via webview_flutter.
- Active maintenance (Readest).

## Consequences
- Requires WebView isolation, bridge protocol, license/SBOM audit.
- Performance and memory must be measured on device (G2).
- epub_rtl remains comparative evidence only.

## Hard gates (must pass before release)
- 30 cross-chapter transitions both directions without discontinuity. (Verified on emulator: monotonic relocations across spine boundaries)
- 100 semantic restoration trials with exact/approximate reporting. (Progress persistence wired; trials pending device execution)
- No unbounded memory growth across 30 transitions. (Pending measurement)
- TalkBack traversal and 48dp touch targets. (Semantics labels added; TalkBack verification pending physical device)
- Hostile-EPUB security tests. (CSP + isolation in place; hostile-EPUB tests pending)

## Validation evidence (emulator-5554, 2026-11-16)
- Continuous vertical scrolling verified: monotonic relocate percentages (0.000779 → 0.003062) across spine boundary (/6/6 → /6/10).
- Mode toggle (scrolled ↔ paginated) preserves semantic position.
- Crash recovery: error stream + bounded retry (3 attempts) + position restoration implemented.
- Typography/theme/layout settings persisted and restored.
- TOC extraction and navigation verified (drawer lists sections, tap navigates).
- In-book search dialog wired.
- Bookmarks: add/list/jump/delete persist across restart.
- 60/60 tests passing; flutter analyze clean.

## Reopen conditions
If a hard gate fails and cannot be remediated, reopen ADR-001.
